# 设计说明

本文档说明玩机工具箱（Modbench）的界面设计：设计原则、主题与颜色、字体、形状、组件、动效和交互规则。代码结构见[架构说明](architecture.md)，编码约束见仓库根目录的 `AGENTS.md`。

文中的类名、变量名均取自现有代码。修改设计时以代码为准，并同步更新本文档。

## 设计原则

- **参照访达**：四种显示方式、列表视图的列、选择规则和大部分快捷键都与 macOS 访达一致，降低熟悉桌面文件管理器的用户的学习成本。与访达不一致的地方需有明确理由，例如 Windows 和 Linux 上用 `Ctrl` 代替 `Cmd`、用 `Alt+Enter` 打开属性
- **工具属性**：界面服务于文件操作，文案简洁、中性，不寒暄、不拟人（详见 `AGENTS.md` 的“文风”一节）。装饰元素仅用于传达状态，例如传输进度的彩虹条、root 模式的红色标记
- **危险操作显式化**：删除、root 模式等不可逆或高风险的操作使用红色或橙色，并通过确认对话框、倒计时、默认聚焦“取消”等方式防止误触
- **随主题变化**：所有颜色都来自主题变量，切换口味和主色时整页（包括页面图标）一起变化
- **可访问**：文字对比度不低于 4.5:1，仅有图标的按钮必须带 `title` 和 `aria-label`，开关类按钮使用 `aria-pressed`，尊重系统的“减少动态效果”设置

## 主题与颜色

### 口味与主色

主题基于 [Catppuccin](https://catppuccin.com/palette)，定义在 `src/index.css`：

- `@theme static` 中写 Mocha 的默认值，`[data-flavor="..."]` 按口味覆盖。使用 `static` 是为了让没被类名引用的颜色变量也输出到 CSS 中，主色切换依赖这些变量
- 四种口味：Latte（浅色）、Frappé、Macchiato、Mocha（深色）。默认跟随系统深浅色，浅色时为 Latte，深色时为 Mocha；用户手动选择后保存在 `afm.flavor`
- 五种主色：Mauve（默认）、Peach、Green、Blue、Rosewater，由 `[data-accent="..."]` 设置，保存在 `afm.accent`。每种主色带一个渐变的另一端 `accent-2`，例如 Mauve 配 Pink
- `index.html` 中的内联脚本在首帧前写入 `data-flavor` 和 `data-accent`，避免刷新时闪烁。`src/lib/theme.ts` 中的键名和取值需与该脚本保持一致

### 颜色角色

组件中只使用以下语义化的主题变量，不使用 Tailwind 默认色板和十六进制值：

| 变量 | 用途 |
| --- | --- |
| `crust` | 页面背景；`accent`、`red`、`peach` 实底上的文字 |
| `mantle` | 主面板、对话框、右键菜单等一级容器的底色 |
| `base` | 容器内的输入框、属性列表、列表视图的隔行底色 |
| `surface0` | 默认按钮、Toast、浮动卡片的底色；分隔线；容器描边 |
| `surface1` | 默认按钮悬停；浮动卡片描边；滚动条；分栏视图中选中路径上的文件夹 |
| `surface2` | 未勾选的复选框描边 |
| `text` | 正文 |
| `subtext0` / `subtext1` | 次要文字、ghost 按钮、菜单图标、对话框说明 |
| `muted` | 提示、列标题、序列号、快捷键提示、隐藏文件名等更次要的小字 |
| `accent` / `accent-hover` | 主操作按钮、选中项、焦点环、文件夹图标 |
| `on-accent` | `accent` 实底上的文字和图标 |
| `red` | 错误、删除、root 模式 |
| `peach` | 警示（`warn`），例如需要再次确认的批量修改 |

`muted` 取 Overlay 2 而不是 Overlay 0 或 1：后两者在深色口味中对 `mantle` 只有 3.6:1 到 4.1:1，达不到 4.5:1。

### Latte 的对比度修正

Catppuccin 原版 Latte 的部分颜色在浅色背景上对比度不足（例如 peach 作文字只有 2.3:1）。`index.css` 末尾按 OKLCH 只降低亮度、保持色相，把这些颜色压暗到满足要求为止，原值写在注释中：

- 会作为文字使用的颜色（主色候选、`red`、`peach`）：在 `surface0` 和自身 15% 底色上不低于 4.5:1
- 仅用作图标和状态点的颜色：在 `crust`、自身 15% 底色上不低于 3:1
- 灰阶：`subtext1`、`subtext0`、`muted` 分别取约 6.0、5.4、4.6:1，在 4.5 到 6.6 之间保持层级
- 主色压暗后，`on-accent` 改用更亮的 `base`

新增颜色或改变颜色用途时，需对四种口味分别核对对比度。

### 透明度与色调

浅色提示块统一用“自身颜色 15% 底 + 自身颜色文字”的写法，例如 `bg-red/15 text-red`、`bg-accent/15 text-accent`。文件类型图标按类型着色：

| 类型 | 颜色 |
| --- | --- |
| 文件夹 | `accent` |
| 图片 | `pink` |
| 视频 | `peach` |
| 音频 | `teal` |
| APK | `green` |
| 压缩包 | `yellow` |
| 文档 | `blue` |
| 代码 | `sapphire` |
| 符号链接 | `flamingo` |
| 其他 | `overlay0` 底、`overlay2` 图标 |

对应关系定义在 `modules/files/components/views/FileIcon.tsx`。

### 主题切换动画

在主题选择器中切换口味或主色时，`switchTheme` 使用 View Transition，让新画面从点击位置圆形扩散到整页（650ms）。浏览器不支持 View Transition 或开启了“减少动态效果”时直接切换。切换过程中页面图标随主色重新生成（`syncFavicon`）。

## 字体

- 正文：`--font-sans`，优先 MiSans VF，依次回退到 PingFang SC、Microsoft YaHei 和系统字体
- 等宽：`--font-mono`，优先 Maple Mono。用于路径、文件大小、百分比、权限位、代码和 `ROOT` 标记

常用字号与字重：

| 场景 | 写法 |
| --- | --- |
| 应用名 | `text-xl font-bold` |
| 对话框标题 | `text-lg font-extrabold` |
| 按钮、菜单项、正文 | `text-sm`，按钮和菜单项为 `font-bold` 或 `font-semibold` |
| 列标题、提示、快捷键 | `text-xs`，颜色 `muted` |
| 传输进度百分比、图标视图的文件大小、设备序列号、主题选择器中的口味说明 | `text-2xs`（11px，`@theme static` 中定义） |

## 形状与层次

界面以圆形和胶囊为主，大容器使用大圆角：

| 元素 | 类名 | 取值 |
| --- | --- | --- |
| 图标按钮、图标底座、复选框 | `rounded-circle` | 50%，正方形元素为正圆 |
| 胶囊按钮、输入框、菜单项、列表行、Toast、任务卡片 | `rounded-full` | 胶囊 |
| 主面板、对话框、属性页、音频播放器 | `rounded-panel` | 2.5rem |
| 主面板内的拖放覆盖层、未连接设备页的说明卡片 | `rounded-4xl` | 2rem |
| 分栏视图、画廊视图、查看器、顶栏下拉面板、图标视图的条目 | `rounded-card` | 1.75rem |
| 右键菜单、首次使用提示 | `rounded-3xl` | 1.5rem |
| 对话框内的错误信息 | `rounded-2xl` | 1rem |

`rounded-circle`、`rounded-card`、`rounded-panel` 是 `index.css` 的 `@theme static` 中定义的 `--radius-*` 变量，其余为 Tailwind 自带的刻度。嵌套的圆角容器按同心关系取值：内层圆角等于外层圆角减去两者的间距，例如拖放覆盖层距主面板边缘 0.5rem，圆角取 2.5rem 减 0.5rem，即 2rem。新增圆角时先从这张表中选择，不使用 `rounded-[...]` 任意值。

层次通过底色、描边和阴影区分：

- 页面背景为 `crust`，主面板为 `mantle`，面板内的元素为 `base` 或 `surface0`，逐级变亮（深色口味中）
- 一级浮层（对话框、右键菜单）为 `mantle` 底、`ring-1 ring-surface0`、`shadow-2xl`
- 浮动卡片（Toast、任务队列、首次使用提示）为 `surface0` 底、`ring-1 ring-surface1`、`shadow-xl shadow-crust/60`
- 模态遮罩为 `bg-crust/70 backdrop-blur-sm`；右键菜单本身为 `bg-mantle/95 backdrop-blur-md`
- `accent` 实底按钮带同色阴影 `shadow-accent/15`，悬停时底色换为 `accent-hover`（主色与 `text` 按 8:2 混合），阴影加深

### 布局

内容区最大宽度 `max-w-6xl`，水平居中，由 `components/shell/ShellLayout.tsx` 提供。自上而下依次为顶栏、模块导航、主面板；文件模块的主面板内依次为工具栏、常用目录、文件视图、状态栏。窄屏时减小内边距（`px-4`，`sm:` 以上为 `px-6`），顶栏中的 `ROOT` 标记在窄屏上隐藏。浮层的固定位置：

- Toast：顶部居中
- 任务队列、首次使用提示：右下角，宽度 `min(24rem, 100vw - 2rem)`
- 对话框：屏幕居中，最大宽度 `max-w-md`，超出屏幕高度时内部滚动
- 右键菜单：贴着指针弹出，距窗口边缘不足 8px 时向反方向翻转
- 多选操作条：底部居中，依次为已选数量、下载、压缩、删除和取消选择；窄屏（`sm` 以下）时压缩和删除只显示图标，并带 `title` 与 `aria-label`，避免超出屏幕

浮层的叠放顺序由 DOM 顺序决定（`z-index` 相同时后出现的在上）：模块页面自己的浮层（查看器、右键菜单、属性页、多选操作条）在前，外壳的任务队列、Toast、对话框在后。因此任务卡片和提示显示在属性页上方，对话框显示在最上层。

## 组件

### 模块导航

`components/shell/ModuleNav.tsx`：位于顶栏下方、主面板上方的药丸形分段按钮，`surface0` 底，高 48px，内边距 4px。每项为 40px 高的胶囊，图标加文字（`text-sm font-bold`）。当前项为 `accent` 底、`on-accent` 文字，底色用 `layoutId` 的弹簧动画在各项之间滑动；其余项为 `subtext0` 文字，悬停时 `surface1` 底。按钮带 `aria-pressed`，容器是带 `aria-label` 的 `nav`。仅有一个模块时不渲染。

### 按钮

按钮统一使用 `components/ui.tsx` 中的两个组件：

- `IconButton`：40px 正圆图标按钮，自动把 `title` 同时设为 `aria-label`
- `PillButton`：40px 高的胶囊按钮，可带图标，文字 `text-sm font-bold`

外观由 `tone` 决定：

| tone | 外观 | 用途 |
| --- | --- | --- |
| `default` | `surface0` 底，悬停 `surface1` | 普通操作、取消 |
| `accent` | 主色实底，带同色阴影 | 每个区域中最主要的操作，例如对话框的确认 |
| `danger` | 红色 15% 底，悬停变为红色实底 | 删除等破坏性操作 |
| `warn` | 橙色 15% 底，悬停变为橙色实底 | 需要注意但可恢复的操作 |
| `ghost` | 无底色，悬停 `surface0` | 选择栏、查看器、媒体控制条中的次要操作 |
| `ghost-danger` | 平时同 `ghost`，悬停变红 | 列表行中不宜过于醒目的删除按钮 |

禁用状态统一为 `opacity-40` 且不响应指针。需要新外观时扩展 `tones`，不在调用处用 `!` 前缀覆盖样式。

### 对话框

`components/overlays/Dialog.tsx` 提供三类对话框：输入（`prompt`，如重命名、新建文件夹）、确认（`confirm`）和书签编辑（`bookmark`）。结构固定为：顶部 64px 圆形图标、标题、内容、底部两个等宽的 48px 胶囊按钮（左侧取消，右侧确认）。

- 确认对话框可设 `tone` 为 `danger` 或 `warn`，图标底色、描边和确认按钮随之变色
- 可附带一个复选框，例如“记住选择”
- 可设倒计时：确认按钮在倒计时结束前不可点击，按钮内有进度填充，且默认聚焦“取消”，防止回车误触
- 重命名时只选中文件名主体，不选扩展名
- 提交失败时在按钮上方显示红色错误信息，并左右抖动一次
- 处理中时按钮文字变为“处理中”，`Esc` 和点击遮罩不能关闭对话框

### 右键菜单

`components/overlays/ContextMenu.tsx`：菜单项为 36px 高的胶囊，左侧依次为对勾位（单选或开关项）、图标、文字，右侧为快捷键提示。危险项为红色。单选压缩包（zip 系、tar、tar.gz、tar.bz2）时，在“打开”之后多一项“解压”（`PackageOpen` 图标）。任何选择（单项、多项、文件、文件夹）在“下载”之后都有“压缩为 zip”和“压缩为 tar.gz”两项（`Package` 图标），点击即执行，不弹对话框；双击压缩包在查看器中显示可展开的目录树，只列条目。快捷键提示中的特殊键用 `KEY_ICONS` 中的 `lucide-react` 图标显示（Mac 上的 `Cmd`、`Shift`，以及 `Enter`、`Backspace`），其余键直接显示文字。

### 提示与反馈

| 场景 | 方式 |
| --- | --- |
| 剪切、拷贝、拷贝路径、权限修改完成等短暂反馈，以及 root 模式退出等异常 | Toast，`surface0` 底；错误时为红色实底 |
| 上传、下载、粘贴、解压、压缩的进度 | 右下角任务队列，进度条为随口味变化的彩虹渐变（`.bg-rainbow`）；完成显示对勾，失败显示叉号，已取消显示禁止图标（`Ban`，`surface1` 底）；压缩任务的徽标和不定进度条为 `peach`。进行中的任务只要有进度就显示百分比和进度条，没有进度时为不定进度条；卡片右侧在进行中且任务可取消时显示取消按钮（`CircleStop` 图标，`title` 和 `aria-label` 为“取消”），不可取消的阶段（例如 zip 推送回设备）按钮消失；结束后换成关闭按钮。带说明的完成任务（zip 跳过了符号链接）显示说明而不是“完成”，且不自动消失；完成和已取消的任务 4 秒后自动移除 |
| 加载中 | 转圈图标；无法确定进度时为来回滑动的进度条（`.animate-indeterminate`） |
| 拖入文件 | 主面板上覆盖主色虚线框，标明将上传到的目录 |
| 首次使用 | 右下角提示卡片，介绍右键菜单和拖拽上传，关闭后不再出现（`afm.tipDismissed`） |
| 对话框中的错误 | 对话框内的红色文字块 |

### 文件视图

四种视图共用相同的状态表示：

- **选中**：图标视图、分栏视图为主色实底（`bg-accent text-on-accent`）；列表视图为主色 15% 底加主色描边，便于在多行中保持可读
- **悬停**：`surface0/70` 底
- **剪切**：被剪切的条目半透明（`opacity-50`），粘贴后恢复
- **隐藏文件**：以点开头的文件名使用 `muted`
- **列表隔行**：偶数行使用 `base/60` 底

分栏视图中，从根目录到当前目录路径上的文件夹为 `surface1` 底，当前选中项为主色实底。

### 设备模式

顶栏的设备选择器和下拉列表用状态点和文案表示 `DeviceMode`，颜色只传达状态，文案同时显示：

| 模式 | 状态点 |
| --- | --- |
| `system` | `green`，连上时 ping 一次 |
| `unauthorized` | `yellow` |
| `offline` | `red` |
| `recovery`、`sideload` | `peach` |
| `bootloader`、`fastbootd` | `blue` |
| 等待重新连接（`reconnecting`） | `overlay0`，沿用原设备名 |

下拉列表每项在序列号旁用 `|` 分隔显示模式文案；找不到 fastboot 时，列表底部显示一行 `muted` 提示。当前模块不支持设备的模式时，页面用 `NoDevice` 显示“设备当前处于 {模式}”和所需的模式，不显示连接引导。

### root 模式

root 模式需要在多个位置同时可见，避免用户忘记当前处于高权限状态：

- 顶栏的盾牌按钮变为红色描边，图标换为带感叹号的盾牌
- 应用名旁显示主色的 `ROOT` 标记
- 标签页标题前加 `ROOT - `，页面图标换为红底图标（`src/lib/favicon.ts`）。页面图标无法读取主题变量，颜色固定为 Mocha 的 Red
- 在 root 模式下删除内部存储、SD 卡以外的路径时（只有这些路径真正用到 root），改用骷髅图标的警告对话框：`danger` 色调，列出受影响的路径，确认按钮倒计时 3 秒，可勾选“不再提示”（`afm.rootDeleteNoWarn`）

## 图标

- 只使用 `lucide-react` 图标，尺寸用 `size-*` 类，常用 `size-4`（菜单、小按钮）、`size-5`（工具栏、顶栏）。顶栏的应用图标为 `Smartphone`，与页面图标的手机图形一致
- 图标底座为正圆，底色为图标颜色的 15% 到 20%
- 不使用 emoji、Unicode 符号和 Nerd Font 字符；快捷键的按键图示参照 `ContextMenu.tsx` 的 `KEY_ICONS`

## 动效

动画使用 `motion/react`，弹簧参数定义在 `components/ui.tsx`，不在组件中另写数值：

| 常量 | 参数 | 用途 |
| --- | --- | --- |
| `spring` | stiffness 500，damping 30，mass 0.6 | 默认：面板、菜单、Toast 进出场，指示条位移 |
| `springPop` | stiffness 550，damping 20 | 带回弹：勾选标记、`ROOT` 标记、图标弹出 |
| `springSlow` | stiffness 80，damping 18 | 缓慢：页面元素入场 |

按压反馈按元素大小分为三档，元素越小缩放越明显：

| 常量 | 按下时缩放 | 用途 |
| --- | --- | --- |
| `pressLarge` | 0.94 | 胶囊按钮 |
| `press` | 0.9 | 图标按钮 |
| `pressSmall` | 0.85 | 色块等小元素 |

常见的进出场写法：

- 浮层进场为透明度从 0 到 1、缩放从 0.9 到 0.97 之间回到 1，并略微位移；退场比进场快（约 0.12 到 0.2 秒）
- 对话框遮罩只做淡入淡出，内容另做缩放
- 错误信息出现时左右抖动一次

### 减少动态效果

`main.tsx` 用 `MotionConfig reducedMotion="user"` 让 Motion 动画遵循系统设置。CSS 动画在 `index.css` 中单独处理：脉冲动画关闭；不定进度条改为静止的半透明整条；加载转圈作为唯一的进行中提示，保留但放慢到 2.5 秒一圈；主题切换不使用扩散动画。

## 交互规则

### 选择

与访达一致，逻辑在 `modules/files/hooks/useSelection.ts`：

- 单击：只选中该项，并以它为连选起点
- `Shift` + 单击：从起点到该项连续选中
- `Cmd` / `Ctrl` + 单击：切换该项的选中状态
- 上 / 下方向键：选择上一项 / 下一项，并滚动到可见；没有选中项时从首项或末项开始
- `Esc`：取消选择

### 快捷键

完整列表见 README 的“快捷键”一节，实现在 `modules/files/hooks/useShortcuts.ts`。设计上遵循以下约定：

- 焦点在输入框、文本框中时不响应全局快捷键；对话框、菜单、属性页或查看器打开时也不响应
- 页面上选中了文字时，`Cmd` / `Ctrl+C` 交给浏览器正常复制
- 焦点在按钮上时，`Enter` 由按钮处理，不打开选中项
- 左右方向键的含义随视图变化：列表视图中展开或收起文件夹，分栏视图中进入或退出目录，画廊视图中切换上一项 / 下一项
- 分栏视图中，空文件夹和无法打开的文件夹不能用右方向键进入，与访达一致
- Mac 上用 `Cmd` 组合键，其他系统用 `Ctrl`；属性在 Mac 上为 `Cmd+I`，其他系统为 `Alt+Enter`
- 新增快捷键时，同步在右键菜单对应项上显示快捷键提示，并更新 README

### 拖放与上传

文件或文件夹拖入窗口时显示覆盖层并标明目标目录，松开后上传到当前目录，保留目录结构。上传、下载和粘贴的进度统一显示在任务队列中。

## 文案

界面文案的措辞规则见 `AGENTS.md` 的“文风”和“界面文案”两节。与设计相关的要点：

- 按钮和菜单项使用动词或动宾短语
- 错误信息说明发生了什么以及如何处理
- 中英文含义一致，同一概念使用同一术语
- 状态用颜色和图标表达，不在文案中使用符号或 emoji
